# Recorded sounds

Drop a sound file here and it replaces the synthesized placeholder with the
same name - no code changes needed. Supported: `.mp3`, `.ogg`, `.wav`, `.m4a`.

| File name | Used for |
| --- | --- |
| `bark.mp3` (or .wav...) | Melody's bark. SUPER BARK plays it louder and deeper. |
| `collect`, `jump`, `celebrate`, `powerup`, `powerdown`, `smash`, `bonk`, `sniff`, `meow`... | The matching sound effect |

Tips for recording Melody: record on a phone close-up, trim it to a single
short "woof" (under half a second), and save as `bark.mp3`.
