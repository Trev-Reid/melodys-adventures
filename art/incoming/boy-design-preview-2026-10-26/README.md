# Boy character design — four-pose preview

This is the agreed design checkpoint before redrawing the full animation sheets. It is **not** a replacement for either 540×752 game sheet.

The four studies are standing, running, climbing from behind, and carrying. They retain the teal hoodie, brown hair, dark shorts and light-soled shoes. The design adds a clearer face and hair silhouette, stronger clothing folds, visible hood and more readable sneakers.

The exported studies use 64×80 cells, 2×2 art pixels, hard transparency and one shared palette of no more than 32 colours. The grounded run still touches the bottom row; no airborne run frame or engine contract change is proposed in this preview.

The football is a separate game texture composited only into the preview, behind the carry pose. It is not painted into the character PNG. Hand-to-ball attachment positions must be checked and finalised across every carry/interaction frame when the complete sheets are drawn.

Next production step after choosing the character design: apply it consistently to all 66 occupied frames in both sheets, retain the six empty cells and 4px gutters, verify ball anchors, then review every animation in the gallery. These four studies do not establish animation timing or transition quality.

Claude: do not install these studies under `public/assets/sprites/`. They are art-direction references only. The original game sheets and layout JSON remain unchanged.
