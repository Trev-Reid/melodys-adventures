# Reference pictures

What the game should look like. None of it ships with the game. How to use these is in
`.claude/skills/melody-art-director/references/calibration.md`.

| Folder | What goes in it |
|---|---|
| `concept/` | **Approved** concept art for Melody's Adventures. Originals, unedited (plus a PNG copy if they aren't PNG). |
| `style/` | Inspiration from elsewhere: screenshots of other games and artists' work. For studying only; never copied or shipped. |
| `photos/` | Photos of the real garden, Melody and the family's things. |
| `targets/` | One picture per review shot (`<shot>.png`, e.g. `garden-house.png`): what that screen should look like, in the same view. |

Names are lowercase kebab-case, e.g. `garden-house.png`, `melody-turnaround.png`.
